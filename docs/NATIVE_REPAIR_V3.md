## Independent changes

- **Exact fallback:** with missing/unsupported/high-risk/disagreeing predictions, startup, stale content/feedback, or a learned-action guard veto, execute the existing 85%-BWE baseline cap exactly. Do not apply another congestion ratchet or upward dwell to that fallback. Guarded decisions cannot masquerade as learned actions. Chrome's congestion controller remains active; BWE remains endogenous, not a known link capacity.
- **Causal content observability:** 32 x 23 features (736 inputs), preserving the existing sender stats and received ACKs and adding texture, motion and validity from the owned pre-marker 40x20 RGB reference. Only source frames whose capture-request time precedes the decision can enter state. Receiver pixels, quality/deadline labels, phase, movie position and future frames never enter inputs. This reuses an already captured sender grid, not an extra GPU readback.
- **Explicit action risk:** each of three risk networks emits seven action heads; weighted Bernoulli gradients supervise only the actually executed factual head. This avoids burying a small one-hot action in a long flattened history. Different action predictions remain estimates, not observed counterfactual outcomes or causal guarantees.
- **Same strict screens:** 10% predicted miss upper screen, 15% disagreement, at least three independent source groups/episodes and 60 requests, unsupported margin 1, 95%-BWE learned ceiling and the native 150 kb/s minimum. ACK roundtrip is not mistaken for one-way presentation age in an absolute congestion cut; it remains a model feature. Sender packet-delay/RTT alarms veto learned control and use the exact baseline.
- **Genuine use accounting:** the >=5% gate counts only the eligible, actually executed learned action that differs from BWE fallback. Startup/dwell/congestion overrides, shadow decisions and baseline-equivalent model choices cannot satisfy it. The original utility/deadline/family/repeatability/tail/group limits are unchanged.
