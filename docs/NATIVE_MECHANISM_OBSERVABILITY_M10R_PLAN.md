that match the existing compact sender state but later diverge in native BWE?

confirmation, stability-prediction exercise, or action experiment. No fitted

technical native-media progression counters remain an acquisition check only.

## Instrumentation and causal availability

The native sampler retains actual anchored 25ms getStats returns. A separate
anchored 100ms browser request receives a **pure, nonmutating** owned-relay
snapshot of offered/dropped/served/queued/forwarded bytes and packets, capacity
integral, pending forwarding, last-pump time, oldest queued age, current service,
service sequence and conservation residual, for both directions. Each snapshot
has a unique sequence, browser request/receipt, Node receive/snapshot/send and
matching persisted Node/browser copies. It becomes usable **only at browser
receipt**. Queue observations do not pump the queue or alter service.

Native records preserve unique outbound/remote-inbound/selected-pair linkage,
field presence, invalid raw values, cap readback, send/packet counters, encoder
target, frames encoded, encode time, packet-send delay and limitation reason.
No QP, PSNR, receiver-frame/deadline or presentation feedback is used. Native
remote-inbound RTCP RTT, total RTT, RTT-measurement count and report count are
recorded, including absence. Candidate-pair ICE RTT is separately named and
**never substituted for RTCP RTT**.

Feedback age is the time since a native report counter (if exposed), otherwise
the explicitly named RTT-measurement counter, was observed to advance. Its
detection interval uses the previous/current actual sender receipt times. The
first preexisting counter has unknown age until its first advance; resets remain
explicit. This is observation/detection age, not the unavailable RTCP-generation
or transport-CC feedback age. Both unavailable generation ages stay `not_exposed`.
Do not claim this assay observes the internal transport-CC estimator state.

All native values become available at their actual sender observation receipt.
At each native record store only the latest already received relay sequence.
Native stats timestamps are preserved unmapped. **No online feature uses any
fitted clock**, including a clock learned later. The unchanged full/beginning
marker mappings validate acquisition offline only. Future BWE is a verification
label, never an online feature.

## Trajectory versus stationary state decision

Report moving-distribution repeatability (future W-infinity ≤0.25) separately
from future stationary labels (frozen ±0.125 causal center and ≤0.05 drift).
Even repeatable moving trajectories do not qualify the stationary/common-support
contract. A separately preregistered trajectory-state development study is
scientifically motivated only if both repeats show the same measured mechanism
contrast associated with divergent trajectories in each content, qualified
channels cover ≥90%, and comparable nondivergent/within-history controls exist.
This motivates a new question, never establishes prediction or action value.
If the assay is mixed or lacks contrasts/controls, report unexplained divergence
and instrument limits. No selected fixed wait or successor allocation.
