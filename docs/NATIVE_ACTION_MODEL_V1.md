# Bounded action-outcome model V1

## Why change the learned model

The V5 checkpoint remains rejected: 0.29% genuine native use before selected recalibration, every action vetoed afterward. Do not alter that model, its thresholds, frozen collectors or role labels. The completed scalar mechanism pilot shows both **low-rate startup source-frame loss** and **higher-rate native playout buffering**. More throughput or a finer bitrate grid alone is not enough. One synthetic group is descriptive mechanism evidence, not policy success or a causal throughput certificate. Its records inform this architecture hypothesis, never neural fitting targets.

## Independent learned candidate

`src/media_rl/native_action_policy.py`, `native_action_learning.py` and `benchmarks/native_rtc/action_policy.mjs` add an independent candidate ABI, `native_factual_action_outcome_v1`:

- **Actual scalar state:** 32 steps / four-second history of native sender telemetry, transported causal presentation ACKs and owned pre-marker content/motion. Scalar encoder cap is never floor-projected. Preserve zero-RTT masking, expiring RTT baseline, reset semantics and strict feature bounds. No phase, relay capacity, future quality/receiver pixels or movie timestamp enters state.
- **Action conditioning:** one state projection plus candidate-cap features predicts bounded **[0,1] normalized per-request sampled utility and miss probability** with a three-seed, 32-hidden-unit ensemble. Ten candidate rates retain the original seven and add 400/450/500 kb/s. Cache the state projection for all candidates. A predicted interpolation is not factual action support.
- **Stable factual objective:** weighted utility MSE and proper miss log loss; no moving Bellman target, unsupported-action max or bootstrap. Label only complete, non-inflight source requests assigned to an acknowledged actual cap. Preserve cold-start misses. These are direct frame outcomes, **not a learned long-horizon environment-return critic**, human perceptual QoE or a convergence guarantee.
- **Train-only skill check:** two physical-source/schedule held-out folds before final three-seed fitting. Each fold uses only its own train subset for normalization/weights and compares against its own factual per-cap priors. Both folds must improve utility MSE by >=1% and not worsen risk Brier before this candidate can select a learned action. Degenerate priors grant zero skill, not a false win. Curves/boundedness/factual skill do not establish causal control gain.
- **Contextual factual calibration:** exact cap × predeclared causal feedback context (`unknown`, `delayed`, `ready`). The context uses only fresh ACK/content flags, ACK roundtrip and presented FPS, not outcomes or trace labels. Fit monotonic probability mapping on calibration labels only; compute worst leave-one-physical-group-out residual plus the existing 0.02 slack. Require >=3 groups, >=3 episodes and >=60 attributed requests **in each exact cap/context cell**. Missing support gets margin 1. Repeated peers/parent aliases never create independent physical groups.
- **Original guards remain:** miss budget 0.1, risk disagreement 0.15, 95%-BWE learned cap ceiling, 500-ms startup/upward dwell, one-adjacent-candidate upward step, sender congestion alarms/hold, native zero target and physical [150,000,4,000,000] cap domain. Fallback is continuous 85%-BWE, explicitly stronger than the old seven-grid fallback. Minimum-cap saturation is a physical fallback exception, not neural safety certification.
