# M9 inherited-gate compatibility audit

This prospective clarification is committed while validation collection is still
running, before any validation BWE/state/future labels have been inspected.
Only original counts and capture statuses have been monitored. It does not edit
the M9 scientific registration, original allocations, prediction rules, labels,
analysis, thresholds, stopping rules or any previous freeze.

The source review of frozen M7RA identified two definitions that need explicit
protection before any claim of native common support:

1. H1 requires **all eligible past-three-second BWE samples** inside the fixed
   target's +/-0.125-octave region. A current-centered D1/P2 caliper together with
   instantaneous target membership does not itself imply that requirement.
2. The inherited measured-probe repeatability gate also checks the existing
   6s/12s 11-sample censuses, full repeat spread<=0.25, prefix W-infinity<=0.25
   and each census's distance from the cell census mean<=0.25.

The unchanged M9 registered results are always reported. In addition, a candidate
must pass this exact inherited audit before being described as qualified for a
future common-state validation. It can only veto a qualification. It cannot
rescue any failed M9 rule, choose another tag/landmark, change a threshold, add a
state representation, infer an action value or authorize a controller.

The audit uses P2's frozen **first tag**, all 64 allocated originals, original
240k..3.8M eligibility, >=27 recent samples, gaps<=250ms and <=0.05 adjacent-second
mean drift. Network feedback is absent throughout M9 and service has already been
acknowledged constant for >=3s at a P2 tag. The 6s/12s probe censuses use the exact
frozen M7RA census function and original four members/history, without rematching.
Missing tags/observations fail. All profiles/range/SD/overlap/entry timing and
future-distribution gates remain those of the frozen M9 primary analysis.

The additional audit reads only qualified sender support observations and fixed
phase windows after the full technical gate and all file checksums pass. No queue,
RTT, encoder, receiver quality, new prediction rule or retrospective feature
search is introduced. Previous freezes and both old successor panels stay closed.
